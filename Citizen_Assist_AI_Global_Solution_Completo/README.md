## Como Executar
1. Abra o terminal na pasta extraída (`projeto_cidadao_v3`).
2. Para rodar o assistente interativo:
```bash
python main.py
```
3. Para rodar o teste automático das 26 perguntas do Golden Dataset:
```bash
python testes_golden.py
```
